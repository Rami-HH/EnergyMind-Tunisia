# EnergyMind - Filtered dataset

Contents: the `dataset` folder (11 assets of a factory power line, Parquet, plus metadata and the original
CC BY 4.0 licence). Details: `dataset/FILTERED_DATASET_NOTICE.md`.

Use: move the `dataset` folder inside the `EnergyMind_Code` folder (next to `src`, `notebooks`, `scripts`).

Dataset: Industrial Asset-Level Electrical Energy Dataset from a Manufacturing Facility (15-Minute Aggregates),
